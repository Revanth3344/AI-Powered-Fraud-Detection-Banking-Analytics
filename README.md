# AI-Powered Fraud Detection & Banking Analytics System

## 📌 Project Overview

An academic project focused on detecting potentially fraudulent
banking transactions using machine learning while integrating
relational database management for transaction storage and analytics.

The project explores how machine learning and database systems
can work together to support fraud detection and banking analytics.

## 🎯 Objectives

- Analyze banking transaction data.
- Develop a machine learning-based fraud classification system.
- Design a relational database for banking transactions.
- Integrate fraud predictions with transaction records.
- Explore banking analytics using SQL queries.

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- MySQL
- MySQL Workbench
